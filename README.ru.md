# Xray Wallpaper

[English](README.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Português](README.pt.md) · **Русский** · [日本語](README.ja.md) · [简体中文](README.zh_CN.md)

Плагин для [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell), который держит вторую картинку за вашими обоями. Вокруг указателя у обоев есть мягкое отверстие, и в нём видно эту картинку.

![Xray Wallpaper](assets/screenshot.png)

Пошагово и с картинками: [руководство по установке и настройке](docs/GUIDE.ru.md).

## Что он делает

Ваши обои DMS остаются на месте. Плагин рисует выбранную картинку на прозрачной поверхности поверх них: внутри отверстия вокруг указателя и больше нигде. Всё, что он не рисует, остаётся чистым, поэтому переходы обоев, виджеты рабочего стола и другие фоновые плагины продолжают работать.

На рабочем столе отверстие следует за указателем; уведите указатель с рабочего стола, и отверстие закроется.

Над окном указатель принадлежит этому окну, поэтому есть второй путь: режим peek. Он открывает круглое окошко с картинкой поверх всех окон, следует за указателем везде и заканчивается по щелчку, через несколько секунд или когда вы отпускаете удерживаемую клавишу.

В niri есть и третий путь: «Следовать за окнами» читает положение указателя из IPC-сокета niri, и отверстие продолжает идти за окнами, а видно его везде, где они прозрачные. Сам по себе niri положение указателя не отдаёт, поэтому нужен niri с моим патчем (см. ниже). С обычным niri настройка скрыта, а два пути выше работают как обычно.

«Непрозрачность верхнего слоя» ниже 100 % пропускает картинку по всему экрану, и всё вместе превращается в смесь двух картинок с чистым пятном вокруг указателя. С «Второе изображение сверху» картинка, наоборот, закрывает обои, а в отверстии видно обои. Размер отверстия, мягкость его края, необязательное кольцо света и скорость, с которой отверстие догоняет указатель, можно настроить.

Картинка накладывается так же, как обои DMS, поэтому растяжение, подгонка и обрезка выглядят так же, как у ваших обоев.

## Требования

DankMaterialShell 1.6.1 или новее. Сам я пользуюсь им в niri. С обычным niri работает всё, кроме «Следовать за окнами»: для этого нужен niri с патчем, см. раздел «Слежение позади окон» ниже.

В niri фоновые поверхности двигаются вместе с рабочими пространствами, если они не лежат в backdrop. Добавьте это в конфигурацию niri, иначе при переключении рабочих пространств картинка уезжает в сторону:

```kdl
layer-rule {
    match namespace="^xray-wallpaper$"
    place-within-backdrop true
}
```

## Установка

Из реестра плагинов:

```sh
dms plugins install xrayWallpaper
dms ipc call plugins enable xrayWallpaper
```

Плагин также есть в каталоге DMS: Настройки → Дополнения. Установка из репозитория:

```sh
git clone https://github.com/satoshoe-dev/dms-xray-wallpaper ~/.config/DankMaterialShell/plugins/XrayWallpaper
dms ipc call plugins enable xrayWallpaper
```

Затем выберите вторую картинку в Настройки → Плагины → Xray Wallpaper. Пока она не задана, на экране ничего не меняется.

## Настройки

Настройки → Плагины → Xray Wallpaper

| Настройка | По умолчанию |
|---|---|
| Второе изображение | нет |
| Второе изображение сверху | выключено |
| Размер отверстия | 260 px |
| Мягкий край | 90 px |
| Светящееся кольцо | 0 px (выключено) |
| Цвет кольца | акцент |
| Непрозрачность верхнего слоя | 100 % |
| Затемнить верхний / нижний слой | 0 % / 0 % |
| Скорость слежения | 4000 px/s |
| Следить на рабочем столе | включено |
| Следовать за окнами | выключено |
| Удержание: сколько держится после клавиши | 800 ms |
| Завершать режим peek через | 20 s |

## IPC

```sh
dms ipc call xray peek toggle     # round view above the windows, also on|off
dms ipc call xray hold            # the same, but only while a key is held
dms ipc call xray at 1280 800     # put the hole at a fixed spot
dms ipc call xray close           # close it again
dms ipc call xray status
dms ipc call xray set radius 400  # any setting from the table above
```

Привязки клавиш в niri, одна как переключатель и одна на удержание:

```kdl
binds {
    Mod+Shift+X { spawn "dms" "ipc" "call" "xray" "peek" "toggle"; }
    Mod+Alt+X cooldown-ms=150 { spawn "dms" "ipc" "call" "xray" "hold"; }
}
```

Привязка на удержание работает через повтор клавиши: каждый повтор отодвигает конец чуть дальше, и вскоре после того, как вы отпустите клавишу, окошко закрывается. Если оно мигает, пока клавиша нажата, увеличьте «Удержание: сколько держится после клавиши».

## Слежение позади окон

Wayland доставляет движение указателя только той поверхности, которая под ним, поэтому ни один клиент не может следить за ним, как только на пути оказывается окно. niri знает положение, но не отдаёт его.

Поток указателя даёт мой собственный патч для niri, в сам niri он не входит. Патч добавляет в IPC отдельный запрос `PointerStream`, который шлёт события `PointerMoved`, так что клиенты, которые его не запрашивают, их и не видят. С niri, собранным с этим патчем, переключатель работает. Обычный niri отвечает на запрос ошибкой; плагин запоминает это и остаётся с датчиком на рабочем столе и режимом peek. Страница настроек тогда скрывает переключатель, а всё остальное работает, как описано выше.

Патч для niri 26.04 лежит в ветке [pointer-stream-v26.04](https://github.com/satoshoe-dev/niri/tree/pointer-stream-v26.04) моего форка niri. Он собирается так же, как сам niri, см. его README.

## Переводы

Страница настроек доступна на немецком, испанском, французском, итальянском, португальском, русском, японском и упрощённом китайском и следует языку, заданному в DMS. Если перевод звучит неправильно, буду рад pull request.
