# Xray Wallpaper: пошагово

[English](GUIDE.md) · [Deutsch](GUIDE.de.md) · [Español](GUIDE.es.md) · [Français](GUIDE.fr.md) · [Italiano](GUIDE.it.md) · [Português](GUIDE.pt.md) · **Русский** · [日本語](GUIDE.ja.md) · [简体中文](GUIDE.zh_CN.md)

## 1. Установить плагин

Из реестра плагинов:

```sh
dms plugins install xrayWallpaper
```

Или клонируйте репозиторий в папку плагинов DMS:

```sh
git clone https://github.com/satoshoe-dev/dms-xray-wallpaper ~/.config/DankMaterialShell/plugins/XrayWallpaper
```

## 2. Включить его

Откройте Настройки → Плагины. Xray Wallpaper есть в списке. Включите его.

![Список плагинов с Xray Wallpaper](images/01-plugin-list.png)

Если его там нет, нажмите «Сканировать» на этой странице или перезапустите оболочку командой `dms restart`.

## 3. В niri: держите слои в backdrop

В niri фоновые поверхности двигаются вместе с рабочими пространствами. Добавьте это в `~/.config/niri/config.kdl`, чтобы картинка стояла на месте:

```kdl
layer-rule {
    match namespace="^xray-wallpaper$"
    place-within-backdrop true
}
```

niri подхватывает изменение сразу после сохранения файла.

## 4. Выбрать вторую картинку

Разверните Xray Wallpaper в списке плагинов и нажмите «Выбрать изображение». Файловый диалог откроется в папке с картинками.

![Страница настроек с файловым диалогом](images/02-choose-image.png)

Ваши обои остаются на месте, а выбранная картинка видна в отверстии. Пока вы её не выберете, на экране ничего не меняется.

## 5. Проведите указателем по рабочему столу

Наведите указатель на свободное место рабочего стола. Отверстие откроется там, где указатель, и будет следовать за ним.

![Отверстие на рабочем столе](images/03-hole.png)

Наведите указатель на окно, и отверстие снова закроется.

## 6. Настроить размер и край

«Размер отверстия» задаёт радиус в пикселях, а «Мягкий край» задаёт ширину перехода между слоями. Широкий мягкий край выглядит как свет лампы, пробивающийся насквозь, узкий выглядит как вырез.

![Размер отверстия и мягкий край](images/04-size.png)

«Скорость слежения» решает, насколько плотно отверстие держится за указателем. На 4000 px/s оно не отстаёт, на 800 px/s плавно едет следом.

## 7. Добавить кольцо света (необязательно)

«Светящееся кольцо» рисует свет по краю отверстия, в вашем акцентном цвете или в цвете текста.

![Отверстие с кольцом](images/05-ring.png)

## 8. Пропустить картинку везде (необязательно)

«Непрозрачность верхнего слоя» решает, сколько обоев остаётся. На 100 % картинка видна только в отверстии. Уменьшите значение, и картинка пойдёт по всему экрану, а отверстие останется единственным местом, где она видна целиком.

![Непрозрачность верхнего слоя на 60 процентах](images/07-opacity.png)

Оба слоя можно ещё и затемнить по отдельности. Затемнение верхнего делает отверстие заметнее, затемнение нижнего оставляет картинку спокойной за вашими значками.

## 9. Посмотреть сквозь окна

Над окном указатель принадлежит этому окну, поэтому датчик рабочего стола его не видит. Режим peek вместо этого помещает круглое окошко с нижней картинкой поверх всех окон:

```sh
dms ipc call xray peek toggle
```

![Круглое окошко поверх окон](images/06-peek.png)

Щелчок его завершает, и таймер из «Завершать режим peek через» тоже. Назначьте его на клавишу, в niri:

```kdl
binds {
    Mod+Shift+X hotkey-overlay-title="Xray: look through the wallpaper" { spawn "dms" "ipc" "call" "xray" "peek" "toggle"; }
}
```

Если вы хотите смотреть только пока клавиша нажата, возьмите вторую команду:

```kdl
binds {
    Mod+Alt+X cooldown-ms=150 hotkey-overlay-title="Xray: look while held" { spawn "dms" "ipc" "call" "xray" "hold"; }
}
```

Эта работает через повтор клавиши: каждый повтор отодвигает конец чуть дальше, и вскоре после того, как вы отпустите клавишу, окошко закрывается. Если оно мигает, пока клавиша нажата, увеличьте «Удержание: сколько держится после клавиши» в настройках.

## 10. Следовать за окнами (только niri с патчем)

Wayland отдаёт движение указателя только той поверхности, которая под ним, и именно поэтому существуют шаги 5 и 9. niri знает положение, но не отдаёт его. Мой патч, который не входит в niri, добавляет в IPC-сокет niri поток указателя, и плагин может брать положение оттуда. С обычным niri пропустите этот шаг: всё остальное в этом руководстве работает без патча. Проверить, какой у вас niri:

```sh
niri msg pointer-stream      # prints positions while you move the mouse
```

Если команда печатает координаты, включите «Следовать за окнами». Тогда отверстие идёт везде, в том числе за окнами, и показывается там, где окно прозрачное. Если niri не знает этой команды, в вашем niri нет потока указателя и переключатель остаётся без действия.

![Отверстие за прозрачным окном](images/08-behind.png)

## 11. Поменять слои местами

С «Второе изображение сверху» ваша картинка становится верхним слоем, а в отверстии видно обои DMS. Пригодится, если вторую картинку вы хотите видеть большую часть времени, например тёмную версию обоев, а под ней яркий оригинал.

## 12. Из скрипта

```sh
dms ipc call xray at 1280 800     # hole at a fixed spot
dms ipc call xray close           # close it again
dms ipc call xray set radius 400  # change any setting
dms ipc call xray status
```

## Если что-то не так

### При переключении рабочих пространств слои уезжают

Нет правила слоя niri из шага 3.

### На рабочем столе отверстие не следует за указателем

«Следить на рабочем столе» выключено, или это место закрыто окном. Датчик видит указатель только там, где рабочий стол свободен.

### Вообще ничего не меняется

Вторая картинка ещё не задана или файл исчез; страница настроек показывает путь, который она использует.

### Виджет рабочего стола перестал отвечать

Датчик лежит под виджетами, так что такого быть не должно. Если это случилось, выключите «Следить на рабочем столе» и пользуйтесь режимом peek.

### «Следовать за окнами» ничего не меняет

Запущенный niri собран без патча потока указателя. В этом случае `dms ipc call xray status` говорит `"stream":"refused"`, и плагин остаётся с датчиком и режимом peek.

### Клавиша удержания мигает

Повтор клавиши медленнее, чем время из «Удержание: сколько держится после клавиши». Увеличьте его или уменьшите задержку повтора у клавиатуры.
